¿Atascado? Pistas progresivas

1. El formulario solo deja subir imágenes, pero el puesto procesa la credencial como un script. Necesitas subir algo tipo .php… y el formulario lo bloquea del lado del cliente.

2. La validación es del cliente (atributo accept + un chequeo JS). El servidor no revalida. Evádela.

3. Lo más fiable: desde F12 → Console, arma y envía tú mismo la petición con un archivo .php:
const fd=new FormData();fd.append('cred',new File(['<?php echo 1;?>'],'cred.php'));fetch('/level/contra/upload',{method:'POST',body:fd}).then(r=>r.json()).then(console.log)

4. (Alternativa) En F12 → Elements, quítale el atributo accept al input y, en el dialogo, elige "Todos los archivos" para seleccionar un .php; luego SUBIR.
